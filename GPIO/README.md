# Prise en main du Raspberry Pi Pico W avec MicroPython : LED et Bouton-Poussoir

Ce laboratoire d'initiation a pour objectif de programmer une carte **Raspberry Pi Pico W** en **MicroPython** afin d'interagir avec des composants d'entrée/sortie de base (GPIO) : une LED et un bouton-poussoir.

---

##  Matériel Requis

* **1x** Carte Raspberry Pi Pico W (avec firmware MicroPython installé)
* **1x** Module LED
* **1x** Module Bouton-poussoir
* Un câble Micro-USB (données + alimentation)
* L'IDE **Thonny** (recommandé pour MicroPython)

---

##  Câblage Indicatif

| Composant | Broche Pico W | Description |
| :--- | :--- | :--- |
| **LED (+ / Signal)** | **GP16** | Sortie numérique (GPIO) |
| **Bouton (Signal)** | **GP18** | Entrée numérique (GPIO avec Pull-Down) |
